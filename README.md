# Sorvetada

Jogo estilo Bomberman para navegador, feito com HTML, CSS e JavaScript puro.

## Como jogar

Abra `index.html` em um servidor local, por exemplo:

```bash
python -m http.server 5500
```

Depois acesse `http://localhost:5500`.

O jogo inclui modo solo, duelo para dois jogadores, vilões com poderes, bombas, cristais de gelo e sprites pixelados.
